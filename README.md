# Academic Projects Portfolio - Efstathios Soultanis

Welcome to my academic projects portfolio. This repository contains practical work, system modeling artifacts, and software prototypes developed during my studies in Applied Informatics (BSc) and Information Systems & Digital Innovation (MSc).

## 📁 Portfolio Structure

### 1. System Analysis & Design
*   **Project Overview:** A complete system analysis and design for the University's Research Ethics and Deontology Committee (EHDE).
*   **Artifacts Included:** 
    *   **Agile Management:** Product Backlog, User Stories, and Epics managed via Kanban principles.
    *   **UML Modeling:** Use Case, Sequence, and Class Diagrams.
    *   **UI/UX:** High-fidelity Mockups simulating the system interfaces.
    *   **Prototypes:** Functional core implementation (Login, Form Submission, and Evaluation workflows) built with Java.

### 2. BPMN-DMN for mitos.gov.gr
*   **Project Overview:** End-to-end business process identification, modeling, and analysis of a public service from the Greek National Register of Administrative Procedures (mitos.gov.gr).
*   **Artifacts Included:** Detailed BPMN 2.0 and DMN (Decision Model and Notation) diagrams mapping out the complete process architecture.
